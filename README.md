# Нативный Android-калькулятор (Kotlin + Jetpack Compose)

Современное нативное приложение калькулятора для Android 8.0 – Android 15 (API 26–35), созданное на **Kotlin**, **Jetpack Compose**, **Material Design 3** и архитектуре **MVVM**.

## Возможности приложения
- **Стандартный и расширенный (инженерный) режимы (`f(x) Инженерный ▾`)**:
  - Базовые вычисления: сложение (`+`), вычитание (`−`), умножение (`×`), деление (`÷`), скобки `( )` с автозакрытием и неявным умножением (`2(3+4)`), смена знака (`+/−`).
  - Сложные инженерные вычисления: тригонометрия (`sin`, `cos`, `tan`) и обратные функции (`sin⁻¹`, `cos⁻¹`, `tan⁻¹`) с переключением углов **DEG / RAD**, логарифмы (`ln`, `log`), квадратный корень (`√x`), возведение в любую степень (`xʸ`) и квадрат (`x²`), факториал (`n!`), константы `π` и `e`.
- **Выпадающая панель настроек (`⚙ Настройки`)**:
  - Расположена в правом верхнем углу и раскрывается плавным окном вниз по аналогии с журналом **«История»**.
  - **Настройки темы**: переключение режима (**Авто / Тёмная / Светлая**) и выбор из 5 цветовых палитр (**Океан, Изумруд, Аметист, Янтарь, Рубин**).
  - **Настройки формы кнопок**: выбор между **Круглыми**, **Скруглёнными** и **Квадратными** кнопками.
- **Полупрозрачные полуобъёмные кнопки с подсветкой нажатия**:
  - Стеклянный полупрозрачный градиент с объёмным 3D-кантом и мягкой тенью.
  - При нажатии вокруг и внутри кнопки возникает мягкая радиальная подсветка: **холодного белого цвета** в тёмной теме и **глубокого тёмно-синего цвета** в светлой теме.
- **Умный расчет процентов (`%`) и высокая точность (`BigDecimal`)**: контекстные проценты (`200 + 10% = 220`, `200 − 15% = 170`), отсутствие погрешностей плавающей точки (`0.1 + 0.2 = 0.3`) и защита от деления на ноль.

## Автоматическое тестирование при сборке
- При каждом запуске пайплайна `Build Android APK` в GitHub Actions выполняются модульные автотесты JUnit 4 (`CalculatorEngineTest` и `CalculatorViewModelTest`) через `gradle test assembleDebug --no-daemon`.

## Как скачать готовый `.apk` на телефон (без ПК)
1. Перейдите на главную страницу этого репозитория на GitHub и откройте раздел **Releases** (или вкладку **Actions** → последний успешный запуск **Build Android APK**).
2. Нажмите на файл **`Calculator-Android-debug.apk`** в разделе **Releases** — скачивание начнется напрямую в браузере телефона.
3. Откройте скачанный `Calculator-Android-debug.apk` и подтвердите установку приложения **«Калькулятор»**.

# Калькулятор для Android

Удобный и быстрый калькулятор для Android (Kotlin, Jetpack Compose, Material 3) с поддержкой обычных и инженерных вычислений.

## Основные возможности
- **Два режима работы**: стандартный калькулятор на каждый день и инженерный режим (`sin`, `cos`, `tan`, `ln`, `log`, степени, корни, факториал, `π`).
- **Точные расчёты**: вычисления на базе `BigDecimal` без ошибок округления, умная работа с процентами и автоматическое закрытие скобок.
- **Журнал вычислений**: сохранение истории расчётов с быстрой подстановкой результата.
- **Настройка интерфейса**: светлая и тёмная темы, 5 цветовых палитр, выбор формы кнопок (круглые, скруглённые, квадратные) и переключение языка (`RU` / `EN`).

## Установка
Скачайте готовый файл **`Calculator-Android.apk`** в разделе **Releases** и установите его на устройство (Android 8.0 и выше).

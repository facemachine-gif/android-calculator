# Нативный Android-калькулятор (Kotlin + Jetpack Compose)

Современное нативное приложение калькулятора для Android 8.0 – Android 15 (API 26–35), созданное на **Kotlin**, **Jetpack Compose**, **Material Design 3** и архитектуре **MVVM**.

## Возможности приложения
- **Верхняя панель быстрого доступа**:
  - Слева — кнопка журнала вычислений **«История»**.
  - Посередине — кнопка переключения расширенного режима **`f(x) Инж.`** (`f(x) Sci`).
  - Справа — кнопка **«⚙ Настройки»** (`⚙ Settings`) с выпадающим окном вниз.
- **Плавный инженерный режим без изменения площади клавиатуры**:
  - При переходе в инженерный режим общая площадь клавиатуры остаётся неизменной: основные кнопки (5×4) плавной анимацией уменьшаются и сдвигаются вправо-вниз, а **сверху** (`DEG/RAD`, `sin`, `cos`, `tan`, `ln`) и **слева** (`√x`, `xʸ`, `log`, `n!`, `π`) появляются дополнительные инженерные кнопки (сетка 6×5).
- **Расширенные настройки (`⚙ Настройки`)**:
  - **Выбор языка (`RU` / `EN`)**: мгновенное переключение интерфейса между русским и английским языками.
  - **Режим темы**: **Авто**, **Тёмная**, **Светлая**.
  - **Наглядная палитра цветов**: выбор темы через цветные круглые значки-плашки с отметкой активного цвета.
  - **Форма кнопок**: выбор между **идеально круглыми** (`1:1 Circle`), **скруглёнными** и **квадратными** кнопками.
- **Полупрозрачные полуобъёмные кнопки с подсветкой нажатия**:
  - Стеклянный полупрозрачный градиент с объёмным 3D-кантом и мягкой тенью.
  - При нажатии вокруг и внутри кнопки возникает мягкая радиальная подсветка: **холодного белого цвета** в тёмной теме и **глубокого тёмно-синего цвета** в светлой теме.

## Автоматическое тестирование при сборке
- При каждом запуске пайплайна `Build Android APK` в GitHub Actions выполняются модульные автотесты JUnit 4 (`CalculatorEngineTest` и `CalculatorViewModelTest`) через `gradle test assembleDebug --no-daemon`.

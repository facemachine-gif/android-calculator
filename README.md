# Нативный Android-калькулятор (Kotlin + Jetpack Compose)

Современное нативное приложение калькулятора для Android 8.0 – Android 15 (API 26–35), созданное на **Kotlin**, **Jetpack Compose**, **Material Design 3** и архитектуре **MVVM**.

## Возможности приложения
- **Стандартные и инженерные вычисления**: сложение (`+`), вычитание (`−`), умножение (`×`), деление (`÷`), скобки `( )` с автоматическим закрытием и неявным умножением (`2(3+4)`), смена знака (`+/−`).
- **Умный расчет процентов (`%`)**: поддерживает как контекстные проценты (`200 + 10% = 220`, `200 − 15% = 170`), так и прямое вычисление доли (`200 × 10% = 20`, `50% = 0.5`).
- **Высокая точность (`BigDecimal`)**: отсутствие погрешностей плавающей точки (`0.1 + 0.2 = 0.3`).
- **Защита от ошибок**: корректная обработка деления на ноль и некорректных выражений.
- **Живой предпросмотр результата**: мгновенный расчет ответа по мере ввода выражения.
- **Журнал вычислений**: сохранение истории операций с возможностью подставить любой прошлый результат одним нажатием.
- **Встроенная панель самопроверки (`Тесты 12/12`)**: прямо на экране приложения доступна кнопка **«Тесты (12/12)»**, которая запускает 12 проверочных сценариев и позволяет подставить любой тест на экран калькулятора одним касанием.
- **Современный дизайн Material 3**: поддержка динамических цветов Android 12+ (Material You), переключение тем (Авто / Тёмная / Светлая), режим Edge-to-Edge и тактильный отклик кнопок.

## Как скачать готовый `.apk` на телефон (без ПК)
1. Перейдите на главную страницу этого репозитория на GitHub и откройте раздел **Releases** (или вкладку **Actions** → последний успешный запуск **Build Android APK**).
2. Нажмите на файл **`Calculator-Android-debug.apk`** в разделе **Releases** — скачивание начнется напрямую в браузере телефона.
3. Откройте скачанный `Calculator-Android-debug.apk` и подтвердите установку приложения **«Калькулятор»**.
